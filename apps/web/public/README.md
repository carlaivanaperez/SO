# Archivos públicos de la web

Poné acá el **logo del almacén** con el nombre exacto **`logo.png`**:

```
apps/web/public/logo.png
```

Next.js sirve esta carpeta en la raíz, así que el logo queda disponible en
`/logo.png` y aparece en el encabezado y en la pantalla de login.

Si el archivo no existe, la app funciona igual (el logo simplemente no se
muestra). Formato recomendado: PNG cuadrado (ej. 512×512).
